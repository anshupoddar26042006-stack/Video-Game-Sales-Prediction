# Video Game Sales Prediction

## Project Overview
This is a Machine Learning project that predicts video game sales using historical sales data and other available characteristics of video games.

The project analyses different factors such as platform, genre, publisher, release year, and regional sales to understand video game sales patterns and build a predictive model.

## Project Objectives
- Understand and explore the video game sales dataset.
- Clean and preprocess the data.
- Perform Exploratory Data Analysis (EDA).
- Identify important features affecting video game sales.
- Build and evaluate Machine Learning models.
- Predict video game sales based on relevant features.

## Dataset
The project uses the `vgsales.csv` dataset.

It contains video game information and sales-related features such as:
- Name
- Platform
- Year
- Genre
- Publisher
- NA_Sales
- EU_Sales
- JP_Sales
- Other_Sales
- Global_Sales
